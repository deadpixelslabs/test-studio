# GLITCH NFT STUDIO v1.3.1 — Mistral Only

Production test build for Vercel.

## Pipeline

User Prompt
-> Mistral structured safety + collection planner
-> Mistral built-in `image_generation` tool
-> Master reference conversation
-> Reference-branch edits for base/overlay traits
-> Chroma-key / difference extraction in browser
-> 10,000 NFT combinations + ERC-721 metadata + ZIP

## Required Vercel Environment Variable

```text
MISTRAL_API_KEY=...
```

Nothing else is required.

Optional overrides:

```text
MISTRAL_TEXT_MODEL=mistral-large-2512
MISTRAL_TEXT_FALLBACK_MODELS=mistral-small-2603,ministral-14b-2512
MISTRAL_IMAGE_MODEL=mistral-small-2603
MISTRAL_TEXT_TIMEOUT_MS=45000
MISTRAL_IMAGE_TIMEOUT_MS=52000
```

## Deploy

1. Import/upload this project into the same Vercel project.
2. Open Vercel -> Settings -> Environment Variables.
3. Add `MISTRAL_API_KEY` for Production (and Preview if you test preview deployments).
4. Remove old `GEMINI_API_KEY` / `GROQ_API_KEY` if you no longer need them.
5. Redeploy.
6. Open `/api/ai-health` and confirm `version: 1.3.1`, `mistralKey: true`, `providerMode: Mistral only`.
7. Open `/api/ai-diagnostics` to verify at least one Mistral planner model returns HTTP 200.
8. Test a normal free-form collection prompt in AI Studio.

## Important

The image endpoint uses Mistral's official built-in `image_generation` tool through the Conversations API. Generated image files are downloaded through the Mistral Files API and returned to the browser as PNG data URLs.

For consistent traits, the master image response stores a Mistral conversation reference. Every base/overlay trait is generated by restarting from the master image entry rather than chaining from the previous trait.

This avoids the old SVG approach and keeps the user's prompt as the source of truth.
